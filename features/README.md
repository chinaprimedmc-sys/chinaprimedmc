# Features

Feature folders compose domain-specific pages from content, shared components and
helpers. Route entry points in `app/` select and render them.

- `tours/`: discovery, detail pages and journey dossier data.
- `destinations/`: destination guides and journey recommendations.
- `journal/`: journal discovery, article reading and related journeys.
- `discovery/`: search results and trip-selection UI.
- `landing/`: high-intent tour landing pages.
- `service-pages/`: service-page composition and routing helpers.

Add future domains when they have a concrete implementation, rather than keeping
empty reserved directories.
