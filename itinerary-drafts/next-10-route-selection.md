# China Prime DMC：下一批10条路线筛选

> 这份清单避开已经完成或已起草的北京—西安—上海、成都、桂林—阳朔、丝绸之路、长江游轮和张家界。判断依据是Western-facing operators、DMCs、OTAs和长期产品目录中的重复上架模式，而不是中国国内旅游热度。旅游公司通常不公开单条路线真实销量，因此“畅销证据”指跨品牌、跨年份持续销售和稳定评论需求。

## 1. 云南经典线：昆明—大理—丽江—香格里拉

- **建议时长：** 9天8晚
- **常见顺序：** 昆明石林 → 大理洱海与古城 → 丽江古城、玉龙雪山 → 虎跳峡 → 香格里拉
- **市场模式：** Audley、Wendy Wu、China Highlights、WildChina、Intrepid和TourRadar长期销售云南线路；大理—丽江—香格里拉是最稳定的Western-facing组合。
- **为什么选：** 它同时提供自然、少数民族文化、古城和轻户外，适合第二次来中国的客户，也容易吸引女性主导的家庭决策者。
- **我们的优势：** 普通线路每天换点、车程长；我们可以在大理和丽江各保留两晚，用私人车调整虎跳峡和玉龙雪山的体力要求，并把香格里拉作为可选高海拔延伸。
- **优先级：** A，核心销售路线。

## 2. 九寨沟与黄龙：成都—九寨沟—黄龙

- **建议时长：** 6天5晚
- **常见顺序：** 成都 → 高铁或航班至川北 → 九寨沟两天 → 黄龙 → 成都
- **市场模式：** China Highlights、Wendy Wu、Odynovo、TourRadar及四川专线运营商持续销售；Western itineraries常把它作为成都熊猫之后的自然延伸。
- **为什么选：** 湖泊、森林和雪山的视觉理解成本低，照片转化强，且能自然承接已经上线的成都路线。
- **我们的优势：** 普通团把九寨沟压成一天并加入黄龙高强度步行；我们保留两个景区日，使用私人接驳，并让黄龙根据海拔适应、天气和长者身体状态决定。
- **优先级：** A，成都自然延伸。

## 3. 江南经典线：上海—苏州—杭州—水乡

- **建议时长：** 6天5晚
- **常见顺序：** 上海 → 苏州园林与运河 → 同里/南浔/乌镇 → 杭州西湖与茶村 → 上海或杭州离境
- **市场模式：** Audley、Wendy Wu、China Highlights、Abercrombie & Kent式定制产品及TourRadar长期重复销售；这是Western market最成熟的上海周边延伸之一。
- **为什么选：** 适合第一次来中国但不想再增加长途飞行的人，也适合长者、情侣和偏好园林、茶与安静城市生活的客户。
- **我们的优势：** 普通产品把苏州和水乡做成拥挤的一日游；我们安排苏州或水乡住一晚、选择一个真正值得看的园林，并避开把多个古镇塞进同一天。
- **优先级：** A，舒适型短线。

## 4. 黄山与徽州古村：黄山—宏村—西递

- **建议时长：** 5天4晚
- **常见顺序：** 高铁抵达黄山北 → 宏村/西递 → 黄山一晚或山下两晚 → 屯溪老街 → 离开
- **市场模式：** Audley、China Highlights、WildChina、Odynovo和摄影型旅行商持续销售黄山模块；评论经常讨论缆车、台阶、云海和住宿位置。
- **为什么选：** 它是国际辨识度较高的中国山岳景观，也有徽派村落作为文化缓冲，不只是登山产品。
- **我们的优势：** 普通团默认山顶住宿和大量台阶；我们提供山顶版、缆车轻量版和古村为主版，提前说明真实步行量，并用私人车解决村落与缆车站之间的复杂接驳。
- **优先级：** A，摄影与自然路线。

## 5. 西藏温和版：拉萨—羊卓雍措—日喀则

- **建议时长：** 7天6晚
- **常见顺序：** 拉萨适应两天 → 布达拉宫、大昭寺 → 羊卓雍措 → 江孜 → 日喀则 → 返回拉萨
- **市场模式：** Audley、Wendy Wu、Explore、China Highlights、Tibet specialist operators和TourRadar长期销售；拉萨—日喀则是比珠峰大本营更普遍、更可控的文化线。
- **为什么选：** 西方客户对Tibet有明确认知和高旅行意愿，能提高品牌深度与客单价。
- **我们的优势：** 不把珠峰当成默认终点；抵达后安排完整适应日，私人车辆随时缩短参观，提前筛查高原风险，并把氧气、医疗点、台阶和酒店供暖写清楚。
- **优先级：** B，高价值但需严格筛选客户。

## 6. 山西古建线：大同—五台山—平遥

- **建议时长：** 7天6晚
- **常见顺序：** 北京/大同 → 云冈石窟 → 悬空寺 → 五台山或应县木塔 → 平遥古城 → 太原
- **市场模式：** Audley、WildChina、China Highlights、Wendy Wu文化线路和铁路型定制产品反复出现；尤其受repeat visitors、建筑和历史兴趣客群欢迎。
- **为什么选：** 它补足网站目前缺少的“古建筑与中国宗教史”产品，且不与西安简单重复。
- **我们的优势：** 普通线路车程密集、讲解偏学术；我们减少寺庙数量，选择真正有代表性的建筑，并为悬空寺提供不上栈道也能理解的替代视角。
- **优先级：** B，品牌深度路线。

## 7. 河南文明线：洛阳—龙门石窟—少林寺—开封

- **建议时长：** 6天5晚
- **常见顺序：** 西安或郑州 → 洛阳 → 龙门石窟 → 少林寺与嵩山 → 开封 → 郑州离开
- **市场模式：** China Highlights、Wendy Wu、Odynovo、TourRadar及文化专线长期组合销售；龙门石窟和少林寺是Western visitors最容易识别的河南景点。
- **为什么选：** “Buddhist art + Shaolin + old capital”故事清楚，既可从西安延伸，也能独立成为中原文化线。
- **我们的优势：** 普通团容易把少林寺变成表演打卡；我们用真正理解佛教艺术和武术文化的英文导游，控制龙门石窟长距离步行，并让武术体验适合孩子而不是强制观看。
- **优先级：** B，适合家庭和文化客。

## 8. 福建土楼与海岸：厦门—南靖/永定土楼—泉州

- **建议时长：** 6天5晚
- **常见顺序：** 厦门鼓浪屿 → 南靖或永定土楼一晚 → 泉州海上丝路遗产 → 厦门离开
- **市场模式：** Audley、China Highlights、WildChina、Odynovo和福建当地DMC持续销售；Western listings通常以UNESCO tulou、Gulangyu和maritime heritage为卖点。
- **为什么选：** 建筑形式一眼可懂，食物和海岸节奏轻松，适合repeat visitors及不想高强度旅行的家庭。
- **我们的优势：** 普通线路一天赶多个土楼群；我们只选一个有生活感的村落，私人车减少换乘，把泉州作为文化章节而非购物停留。
- **优先级：** B，轻松型特色路线。

## 9. 香港与澳门延伸

- **建议时长：** 5天4晚
- **常见顺序：** 香港岛与九龙 → 离岛/大屿山可选 → 快船或大桥至澳门 → 香港离境
- **市场模式：** Audley、Abercrombie & Kent式定制产品、Intrepid、G Adventures、Viking land extensions及大量OTA listings长期销售；是国际航班前后最成熟的China add-on之一。
- **为什么选：** 对西方客户理解成本极低，航班连接强，适合作为内地路线的到达或离境缓冲。
- **我们的优势：** 普通产品容易变成维港、山顶和赌场清单；我们强调社区、海港历史、餐饮和私人接送，并明确跨境行李、口岸和签证安排。
- **优先级：** A，强延伸产品。

## 10. 哈尔滨冬季线：冰雪大世界—老城—雪乡可选

- **建议时长：** 5天4晚
- **常见顺序：** 哈尔滨老城与中央大街 → 冰雪大世界 → 太阳岛/虎园可选 → 雪乡或亚布力两日延伸
- **市场模式：** Wendy Wu、China Highlights、TourRadar、冬季摄影团和OTA在每个冬季重复上架；Ice and Snow Festival具有稳定国际认知。
- **为什么选：** 网站需要一条明确的冬季旅行理由，它能在传统淡季制造询盘，也适合家庭和摄影客户。
- **我们的优势：** 普通团常忽略极寒条件和长时间户外等待；我们提供私人暖车、短时段参观、室内恢复点、儿童和长者装备清单，并把雪乡从默认项目改为可选。
- **优先级：** B，强季节性产品。

## 建议上线顺序

### 第一批：最容易卖、最符合现有客群

1. 云南经典线
2. 江南经典线
3. 九寨沟与黄龙
4. 黄山与徽州古村
5. 香港与澳门延伸

### 第二批：建立专业深度和季节覆盖

6. 西藏温和版
7. 山西古建线
8. 河南文明线
9. 福建土楼与海岸
10. 哈尔滨冬季线

## 暂不优先的路线

- **珠峰大本营：** 高原和长车程与核心长者客群冲突，先用拉萨—日喀则版本测试需求。
- **新疆大环线：** 距离过长、季节性强，第一批产品的运营解释成本较高。
- **海南度假：** 对Western inbound leisure的差异化不足，容易与全球成熟海岛产品直接竞争。
- **贵州深度线：** 文化价值高，但Western market认知与搜索需求弱于上述10条，更适合后期内容型产品。
- **峨眉山—乐山：** 与已经上线的成都路线重叠，可作为成都升级选项，不应另占一个主产品位。
