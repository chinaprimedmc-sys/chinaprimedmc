## 2. 战略定位

### 2.1 品类定义

AVIORA 不是简单的旅行社，也不是只卖景点的线路网站；它是一个**中国本地、面向国际客人的旅行设计与落地伙伴**。价值发生在“选择、编排、解释、照应”四件事上。

### 2.2 竞争位置

建议占据以下空位：

> 在大型平台的标准化跟团与超高端奢华顾问之间，提供有文化判断力、节奏舒服、执行可靠且价格逻辑透明的私人中国旅行。

### 2.3 客户洞察

国际客人购买的不是“更多景点”，而是：

1. **降低不确定性**：支付、交通、门票、酒店登记、语言和临时变化有人处理。
2. **避免被游客化**：不想被赶行程、被带去购物点或只看表面符号。
3. **获得解释权**：希望知道一个地方为什么重要，而不是只拍照打卡。
4. **把时间花在值得的地方**：愿意为路线取舍、酒店位置和好向导付费。

### 2.4 品牌价值公式

**本地事实** × **专业取舍** × **人性化节奏** × **持续照应** = AVIORA 体验

任何营销内容都应至少证明其中两项，避免只说“美、奢华、难忘”。

## 3. 品牌核心

### 3.1 Purpose（存在理由）

让世界更有信心、更有深度地走进中国；让中国旅行从一次复杂的安排，变成一段值得回味的个人经历。

### 3.2 Vision（愿景）

成为国际客人理解中国、进入中国、安心旅行中国时最值得信赖的本地伙伴。

### 3.3 Mission（使命）

用真实的在地知识和严谨的执行，把每一段路线设计得更清楚、更从容、更贴近旅客本人。

### 3.4 Values（价值观）

| 价值观         | 行为标准                                                     |
| -------------- | ------------------------------------------------------------ |
| 有判断，不堆砌 | 敢于删掉不必要的城市、景点和酒店；说明取舍理由。             |
| 先照应，再惊喜 | 先确认签证、饮食、行动能力、房型、交通和联系人，再设计亮点。 |
| 尊重真实       | 不把社区、传统或人物当布景；用准确语境讲述中国。             |
| 透明负责       | 价格、包含项、限制条件和替代方案写清楚；发生变化主动说明。   |
| 从容有温度     | 回复及时但不催促；给客人留出停留、休息和临时改变的空间。     |

### 3.5 Brand essence（品牌本质）

**Considered China**：被认真理解的中国，也被认真安排的旅行。

## 4. 品牌个性与表达格调

### 4.1 个性维度

克制 70% / 热情 30% · 知性 65% / 轻松 35% · 当代 60% / 传统 40% · 安静 65% / 戏剧 35%

### 4.2 四个感受关键词

- **Clear 清楚**：少用空泛形容词，多给具体决定。
- **Grounded 在地**：说得出时间、距离、位置、季节和现实限制。
- **Cultured 有文化**：有背景、有观察，但不卖弄知识。
- **Cared for 被照应**：让客人感到有人记得细节，也有人处理变化。

### 4.3 文案声音

**应该像**：一位见多识广、审美克制、愿意认真听需求的中国朋友。  
**不应该像**：景区广播、廉价促销页、旅行文学仿写、浮夸奢侈品广告。

**写作规则**

1. 先事实，后感受：先写“住在西湖边两晚”，再写“让清晨属于湖面”。
2. 用动词和名词：hotel location、room category、guide、vehicle、timing、support。
3. 英文句子短、准确、少感叹号；中文自然、具体、不端着。
4. 不滥用 `luxury`、`seamless`、`curated`、`unforgettable`、`hidden gem`。
5. 所有“可提供”都要对应流程；所有“保证”都要对应书面确认。

**示例**

- 不推荐：A luxurious, seamless and unforgettable China experience.
- 推荐：A private route with well-located hotels, early access where possible, and one China-based team throughout.

## 6. 视觉识别建议

### 6.1 现有基础

- 现有 logo 资产：`public/brand/aviora-logo.webp` / `.jpg`。
- 现有官网已采用米白、墨黑、灰绿/森林色与衬线大标题，整体偏编辑型、安静、高级。
- 视觉不应突然转向金色、黑金、过度装饰的传统“奢华旅游”风格。

### 6.2 推荐色板

| 角色   | 色值      | 用法                   |
| ------ | --------- | ---------------------- |
| Ink    | `#161512` | 主文字、深色背景、按钮 |
| Ivory  | `#FAFAF7` | 主背景、留白           |
| Sand   | `#F0EFEB` | 分区、卡片、表格底色   |
| Muted  | `#6F6C66` | 次级文字、说明         |
| Moss   | `#607868` | 标签、信任、少量强调   |
| Border | `#E2E0D9` | 线框与分隔             |

色彩比例建议：Ivory/Sand 70%，Ink 20%，Moss 8%，其他强调色不超过 2%。

### 6.3 字体与版式

- **显示字体**：现有 `font-serif`（Georgia/Cambria fallback）；用于大标题、引语和章节标题。
- **正文/界面**：现有 Inter/system sans；用于导航、行程、价格、表单和说明。
- 大标题字距收紧、行高紧凑；正文保持 1.6–1.8 行高。
- 使用大留白、细边框、非对称图片裁切和少量编号（01/02/03）建立编辑感。
- 不使用大面积渐变、金属纹理、龙凤祥云等直白符号。

### 6.4 摄影与视频

优先顺序：真实光线 > 人的状态 > 空间细节 > 地标全景。  
拍摄内容：清晨/黄昏、街区关系、手部与材质、向导交流、真实交通转换、酒店位置感。  
避免：摆拍式“外国人举长城”、过度饱和、无人景点假象、把少数民族服饰当装饰。

每条线路至少准备：1 张英雄图、1 张人物/服务图、1 张生活细节图、1 张交通或酒店图。

### 6.5 AVIORA 视觉方向 02：Quiet Cartography

这是建议采用的正式视觉概念：**Quiet Cartography（静默的地图）**。它不是“东方风”装饰，而是把地图、纸张、墨线、旧建筑的阴影和当代酒店的材质，转译成一种安静但有方向感的旅行品牌。

品牌画面应让人感到：**有距离，但不疏离；有历史，但不复古；有审美，但不炫耀。**

#### 核心色彩系统

不建议继续把纯黑 `#161512` 作为唯一品牌色。它适合正文，但不够独特。推荐建立以下五色系统：

| 色彩角色   | 名称            |       HEX | 使用比例与场景                       |
| ---------- | --------------- | --------: | ------------------------------------ |
| 主底色     | Rice Paper      | `#F5F1E8` | 45%；官网主背景、行程册内页、留白    |
| 主深色     | Ink Black       | `#1B1C19` | 25%；正文、导航、深色页、主按钮      |
| 品牌识别色 | Pine Shadow     | `#30483D` | 15%；标题强调、标签、链接、深色背景  |
| 温度色     | Oxidised Copper | `#A66A4B` | 8%；编号、细线、hover、小面积重点    |
| 辅助底色   | Celadon Mist    | `#DDE4DC` | 7%；信任区、表单、行程提示、浅色模块 |

**配色规则**：Rice Paper + Ink Black 是默认组合；Pine Shadow 负责识别；Oxidised Copper 只做“印章”一样的点睛，不能大面积铺色。禁止金色渐变、亮红色、紫色和高饱和旅游海报色。

#### 推荐字体系统

现有 Georgia/Inter 可以继续作为 fallback，但正式品牌不应只依赖系统字体。建议采用以下组合，并为中文准备同等质量的字形：

| 层级            | 英文推荐                                 | 中文推荐        | 使用方式                                         |
| --------------- | ---------------------------------------- | --------------- | ------------------------------------------------ |
| Display Serif   | `Cormorant Garamond` 或授权后的 `Canela` | `Noto Serif SC` | H1、章节标题、品牌引语；字重 400–500             |
| Editorial Serif | `Newsreader`                             | `Noto Serif SC` | 长标题、目的地故事、行程册章节页                 |
| Sans            | `Manrope` 或 `Inter`                     | `Noto Sans SC`  | 导航、表单、价格、说明、CTA；字重 400–650        |
| Micro Label     | `IBM Plex Mono`                          | `Noto Sans SC`  | 日期、编号、路线代码、资质信息；只做小面积信息层 |

**字体比例**：Serif 55% / Sans 40% / Mono 5%。  
**中英混排**：中文正文不使用英文衬线字体替代；中文行高 1.75–1.9，英文大标题行高 0.9–1.05。  
**字距**：品牌字标保持原始字距；英文全大写导航 `0.14–0.18em`；中文标题不要强制增加字距。

#### Logo 使用

- 现有 AVIORA 图形标志可以保留为主标，但应输出透明背景 SVG/PNG、深色版、反白版和单独图形符号版；当前 JPG/WebP 白底不适合作为完整品牌资产。
- Logo 四周最小留白为字标高度的 `0.75x`；不加阴影、描边、渐变或图标外框。
- 官网导航使用横向字标；封面、行程册和社交头像使用图形符号；不要在每个模块重复完整 logo。
- “AVIORA”正文中统一全大写；只有在叙事性标题中可使用 `Aviora` 作为排版实验，不作为正式拼写。

#### 版式比例

- 页面最大内容宽度：`1280–1440px`；正文阅读宽度：`640–720px`。
- 使用 12 栏网格；图片常用 7/5、8/4 或全宽留白构图，避免所有卡片等宽排列。
- 章节编号用 `01 / 02 / 03`，颜色使用 Oxidised Copper 或 Pine Shadow；编号是导航节奏，不是装饰。
- 卡片圆角控制在 `0–12px`；品牌主视觉和高端报价单优先使用直角或微圆角，不使用大面积玻璃拟态。
- 边框使用 `1px`、低对比度；阴影应几乎不可见。高级感来自留白、比例和材质，不来自投影。

#### 图像处理

- 默认使用自然色温、低饱和、保留阴影；不要统一套橙色滤镜。
- 图片上叠加文字时，优先使用 Rice Paper 实色面板或渐隐遮罩，不在复杂画面上直接压白字。
- 人物照片必须有关系和动作：交谈、观察、行走、用餐、等待；避免正面摆拍和“游客举旗”视角。
- 地标照片只承担定位功能；品牌记忆应更多来自门、窗、桌面、街道、手势、光线和转场。

#### 材质与印刷感

行程册、报价单和欢迎信建议使用 Rice Paper 底色、Pine Shadow 标题、Copper 编号；可加入极轻的纸张噪点或地图等高线，但透明度低于 5%，不可影响阅读。数字文件不要模拟昂贵烫金；如果线下制作，优先选择无涂布纸、压凹、单色专色印刷。

#### 应避免的视觉信号

金色奢华、红黑中国风、书法标题、龙凤祥云、景区剪影、护照章堆叠、过多航线虚线、满屏圆角卡片、过度炫技的 3D 动效。这些会把 AVIORA 拉回“旅游产品促销”而不是“有判断力的旅行品牌”。

## 7. 服务落地标准

### 7.1 客户旅程

`发现 → 对话 → 方向建议 → 报价与确认 → 出发前照应 → 在华执行 → 回访与复购`

### 7.2 每阶段品牌动作

| 阶段     | 必须交付                                                          |
| -------- | ----------------------------------------------------------------- |
| 发现     | 内容先回答“适合谁、什么节奏、现实难点”。                          |
| 对话     | 24 小时内确认收到；记录日期、同行人、预算、兴趣、饮食和行动需求。 |
| 方向建议 | 给出 1 个主方案 + 1 个替代方案，并说明取舍。                      |
| 报价确认 | 明确酒店等级/房型假设、包含/不含、取消规则、付款主体和有效期。    |
| 出发前   | 提供一份可读的最终行程、联系人、支付/网络/登记提示和紧急流程。    |
| 在华执行 | 单一联系人；变更先解释影响，再给选项。                            |
| 回访     | 48–72 小时内回访；记录反馈并进入产品改进。                        |

### 7.3 服务语言

- 用“我们建议 / 这里的取舍是 / 如果你更在意 X，可以换成 Y”。
- 不用“绝对最好 / 顶级 / 100% 无忧”。
- 对不确定事项写“subject to confirmation / 以书面确认结果为准”。

## 8. 内容与渠道落地

### 8.1 内容支柱

1. **Read China**：城市、历史、饮食、社区和当代生活的解释。
2. **Plan China**：签证、门票、酒店登记、铁路、支付、季节和行动能力。
3. **Travel China**：真实线路、节奏、酒店位置、向导和交通细节。
4. **Meet AVIORA**：团队、资质、服务流程、无强制购物和客户反馈。

建议内容比例：40% 实用规划，30% 目的地解释，20% 产品案例，10% 品牌与团队。

### 8.2 渠道语气

- 官网：完整、安静、证据优先。
- Instagram：一张画面 + 一个具体观察 + 一个可执行建议。
- WhatsApp/邮件：简洁、明确下一步，不连续发送营销话术。
- B2B 提案：增加供应链、响应 SLA、资质、风险处理和可定制边界。

## 10. 品牌治理

### 10.1 资产管理

建立唯一品牌资料夹：`brand/01_strategy`、`02_logo`、`03_typography`、`04_colour`、`05_photography`、`06_templates`、`07_legal-proof`。所有外发文件标注版本和日期。

### 10.2 发布检查

- 是否说清楚对象、路线、节奏和下一步？
- 是否有可验证的服务证据？
- 是否把建议写成保证？
- 是否同时符合 AVIORA 的克制、在地和可靠？

- 图片是否真实、尊重人物和社区，并有准确 alt 文本？

### 10.3 建议 KPI

品牌层：品牌搜索量、直接访问占比、信任页浏览深度、内容收藏/转发率。  
业务层：咨询到有效需求率、报价接受率、平均响应时间、改签/投诉率、复购/转介绍率。  
体验层：行程满意度、向导评分、信息清晰度评分、问题首次解决率。

## 11. 90 天落地路线图

**0–30 天：统一基础**

- 确认 tagline、定位句、品牌架构和法律主体写法。
- 清理官网所有重复/夸大形容词；统一 CTA、联系方式和资质表述。
- 建立 logo、色板、字体、摄影和文案模板。

**31–60 天：建立证据**

- 为 4 条旗舰线路制作完整案例页：路线取舍、酒店逻辑、向导、交通和实际限制。
- 上线团队/资质/预订流程内容；收集可授权的真实反馈。
- 为销售建立报价模板、行程模板和变更处理模板。

**61–90 天：形成增长系统**

- 按四大内容支柱发布 SEO 与社媒内容。
- 对首页 CTA、咨询表单和 About 页做转化测试。
- 每月复盘搜索词、咨询质量、成交原因和未成交原因，反哺产品。
