# 03｜西安兵马俑私人一日游：产品与 SEO／GEO 优化

内容更新：2026-11-10。范围：第三条产品，西安兵马俑私人一日游。已完成本地内容与代码修改，尚未发布；供应成本、实时景区规则和浏览器视觉验收仍需核实。

## 为什么保留这条产品

归属：一日体验 → 城市与景区一日体验。

**服务已经安排西安住宿、希望有人处理接送、博物馆门票和现场讲解的客人。以理解兵马俑为当天重点，再根据时间与体力安排一段古城步行。**

它与西安—北京六天线的区别是只买西安的一天，不包含住宿、城际交通、北京或长城。它也不是从北京或上海出发的往返一日游，更不是只提供车辆的接送服务。

优先客群为初访西安的情侣、家庭与小型私人团。对儿童、年长旅客和轮椅使用者，按真实步行、站立和辅助需求评估；取消笼统的 Senior-friendly、Mobility-aware 和 Easier pace 展示／筛选标签，不把私人接送等同于低体力消耗或完全无障碍。

## 核心路线与日程取舍

| 环节                   | 规划时间                                 | 服务和边界                                                   |
| ---------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 酒店接客、前往临潼     | 通常约 08:30–09:00；路上约 1–1.5 小时    | 中心酒店出发；时间随酒店、入场安排与交通调整                 |
| 入场                   | 随现场条件变化                           | 标准门票、身份与安检流程；不保证跳过排队                     |
| 主要展坑               | 约 2.5–3 小时                            | 计划参观开放的一、二、三号坑；顺序、展品与可用区域随现场调整 |
| 午餐                   | 约 45–60 分钟                            | 自理或提前选购；不默认包含清真餐或饮食验证                   |
| 返回市区和一段古城步行 | 返回车程约 1–1.5 小时；步行约 45–60 分钟 | 钟鼓楼周边、回民街巷或城墙外观中选一段，不默认全部走完       |
| 酒店送回               | 通常约 16:30–17:00                       | 全日约 8 小时为规划参考，书面服务窗口与具体方案为准          |

交通、安检、队列、用餐及博物馆兴趣深度都会改变用时。不能把这些时间范围相加后当成固定承诺，也不能默认任何下午航班或高铁都能赶上。

选购城墙登城、陶俑手作或其他项目时，明确是替换古城步行还是另加用车用导时间。不要在标准八小时内无条件叠加所有项目。

## 包含与不含

核心包含：确认范围内的中心酒店往返、私人空调车辆与独立司机、确认语种的私人导游、标准兵马俑博物馆入园票、选定的一段古城步行、饮用水及无强制购物。

不自动包含：午餐和饮料、城墙与钟鼓楼内部门票、自行车、手作陶俑、付费品尝、额外馆内交通、机场与火车站接送、额外服务时间。

私人的是导游、车辆和服务安排；展厅、安检和公共街巷与其他游客共享。没有 VIP、免排队、空馆、特定机位或限制区域访问承诺。标准导游不等于已确认的考古学家。

“博物馆票覆盖哪些范围”和“当天带客实际参观哪里”分别回答。核心导览是兵马俑主要展坑区域，不默认包括骊山园、所有附属展览或额外园区间接送；不提供秦始皇墓室进入项目。若客户关心延伸区域，应先核实当日票项、运营与转场，再确认方案。

计价口径：一份私人团书面总价。已移除原目录中的未核实分人数金额与升级参考价，保留 quote-only。兼容字段 `basePartySize: 4` 不据此计算或公开该产品价格。
