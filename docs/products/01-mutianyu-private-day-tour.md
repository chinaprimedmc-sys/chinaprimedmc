# 01｜慕田峪长城私人一日游

产品整理日期：2026-11-10。此次为本地网站产品与页面优化，未发布上线，也未重新核实供应商价格。

## 产品为什么存在

**为已经订好北京住宿的客人，把长城这一天的接送、入园、登城方式、步行路线和返程安排清楚。**

归属：一日体验 → 城市与景区一日体验。

优先客群：北京初访客、情侣、小型私人团，以及愿意提前说明儿童年龄和步行需求的家庭。年长客人可以提出较短路线需求，但不能仅凭年龄承诺适用；所有路线都存在台阶、坡度与不平地面。

与北京五天线的边界：只购买长城一天，不含北京住宿、机场接送和完整城市游览。客人尚未安排北京全程时，应推荐北京五天线；希望继续安排全国旅行时，再推荐初访经典或成熟旅客慢游线路。

## 对外销售的三个游览选择

三个选择共用同一个产品，不新建三条重复线路。

| 选择               | 适合的需求                           | 步行说明                                     | 报价处理                             |
| ------------------ | ------------------------------------ | -------------------------------------------- | ------------------------------------ |
| 往返封闭式缆车     | 希望减少登城前爬升，把体力留在长城上 | 到达长城后仍有台阶、坡度，不承诺无障碍       | 在私人团总价中列明选购票项           |
| 步行上下           | 主动希望较长爬升、有相应体力与时间   | 爬升和下坡显著增加，需提前审核当天路线       | 核心服务含门票及景区摆渡，不加缆车票 |
| 吊椅上行＋滑道下行 | 能接受开放式吊椅，并符合运营方限制   | 长城仍需步行，需确认年龄、身高及替代下山方式 | 选购票项单列，说明停运时如何处理     |

封闭式缆车与吊椅／滑道使用不同进出位置。单程或混用路线需要单独核实，不默认票券互通。导游和车辆为私人服务；景区、摆渡和山地交通与其他游客共享。

## 核心服务与费用边界

核心服务：确认服务范围内的北京酒店往返、独立司机及空调车辆、确认语种的私人导游、慕田峪入园与景区摆渡、车内饮用水、出发前的接送和路线确认、无强制购物。

单独确认：缆车／吊椅／滑道、午餐、非中心城区或机场接送、超出约定时间的用车用导、特殊设备及其他附加服务。任何选购服务只有出现在书面包含清单中，才算已包含。

**报价单位为整团总价。** 已移除原 US$198／人、四人合计 US$792 与未核实的山地交通参考金额。未用推算金额替代供应商实价。代码中的 `basePartySize: 4` 仅用于兼容现有目录类型；该产品没有数字起价，不据此计算或展示价格。

## 行程节奏

通常全程 7–9 小时；单程车程约 1.5–2.5 小时仅作规划参考；现场长城游览通常预留约 2–3 小时。交通、排队、步行登城、午餐与天气均会改变节奏。旺季可能延长，不保证固定返城时间。

接单时先问火车、航班或晚间预约等硬性截止时间，再判断是否能承接，不默认一天长城游可与任意晚班交通衔接。

## 询价到确认

1. 收集日期、成人与儿童人数及年龄、酒店完整地址、返程地点、截止时间、导游语种、登城偏好及步行／恐高情况。
2. 核对车辆、导游与所选景区服务可用性，判断步行方案和备选下山方式。
3. 书面报价列出整团总价、服务时段、核心包含、所选票项、额外接送、午餐及变更取消条件。
4. 按合同与付款安排确认；收到询价本身不代表已预订。
5. 出行前发送接送时间、联系方法、入园要求、登城和返程方案；票务所需资料通过适当的预订渠道收集，不要求客人在初始公开询价中填写证件号码。
