# 02｜上海私人一日游：产品与 SEO／GEO 优化

内容更新：2026-11-10。范围：上海一日游及支撑它的公共展示逻辑；未将其余 17 条产品逐条改写。本次尚未发布。

## 定位与购买理由

归属：一日体验 → 城市与景区一日体验。

**为已有上海住宿、希望用一天理解这座城市的客人，安排私人导游、独立司机、门票、地区间接送和返程。** 核心体验是古典园林、旧城、黄浦江两岸和原法租界街区之间的联系。

主客群：初访上海的情侣、家庭、小型私人团。年长旅客根据实际步行和登船能力审核路线；不以年龄标签替代适用性判断。

标准行程约 8 小时，从中心酒店出发和返回。机场转机和游轮岸上观光属于另一份接送与时限方案，不能直接把酒店一日游的服务范围套上去。

- 新的 metadata 入口保留该产品人工写定的 title／description，不自动挤入年份和通用 CTA。

- 15 条产品问题＋2 条预订政策问题均在可见 FAQ 中；原生 details 折叠保留正文，不要求点击后加载答案。

- 使用 TouristTrip、WebPage、FAQPage 和 BreadcrumbList；未核实价格不生成 Offer。
- 全部静态行程的 FAQPage 与页面显示范围共用函数，消除原先 schema 描述未显示 FAQ 的差异。
- 产品已有的上海相关长线推荐现在实际显示，替代此前自动推荐其他城市一日游的行为。

## GEO 与 AI 可理解性

首段是一段自足的事实摘要：地点、时长、私人服务、导游和司机、主要路线、已含票项、另付项目、接送范围都能独立理解。

新增实用信息清单，和结构化数据、`llms-full.txt` 复用同一组事实。`llms.txt` 从目录读取同步后的产品和计价口径。完整 AI 文本目录还补充慕田峪已有的三种登城选择，避免新增页面配置遗漏在文本目录之外。

品牌与 provider 继续指向站点现有 operator 实体；没有新增虚构作者、奖项、专属评价、供应核实声明或独立第三方背书。内容更新日期不等于供应价格核实日期。

`llms.txt` 是补充发现入口。可见 HTML、可抓取链接、正确事实及正式索引才是基础；不能把文本文件当作保证被 AI 引用的机制。
