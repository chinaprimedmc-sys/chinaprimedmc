# 全国城市与高端小众目的地二次缺口核查

2026-11-11。仅本地修改，无提交、推送或部署。

## 核心结果

本轮起点为463项候选、65篇完整指南、66项指南覆盖、397项待处理。进一步抽查11个省级分组，发现94项尚未入库的旅行实体，已写入内部候选库。当前为 **557项候选、65篇指南、66项覆盖、491项未登记独立/组合指南覆盖**。候选覆盖比例约11.8%，不得称为全国城市覆盖率。

491是当前编辑台账待处理数量，不是全国还差491座城市，也不表示必须新增491篇。清单混合城市、县域、村镇、景区和文化景观；父子实体需要分别解决问题，但可以由有实质答案的组合指南承接。景洪/西双版纳、澜沧/景迈山、德清/莫干山等须先审核已有正文和搜索意图，再决定扩大组合覆盖、改进父页或独立建页；不能仅因新增候选就宣称现有指南完全未提及。

**全国每个城市的最终缺口仍未核定。** 本轮尝试连接民政部官网，curl返回无法解析主机，未取得带日期的官方底表。新增分类、上级与英文名是编辑识别信息，均标注待官方名录核对，不能用作行政认证。未取得实时搜索量和关键词难度数据。

## 全国全城市的验收口径

1. 建立带官方来源、版本日期、行政代码的大陆城市底表，逐条纳入直辖市、地级市、县级市。自治州、地区、盟及有旅行价值的县另列，不借地级市替代。
2. 港澳台分别按当地实体体系整理，经营、入境与跨境衔接另验；不可用一个省级标签表示所有旅游目的地已覆盖。
3. 对官方底表做集合差异：未入候选库、已入库但未回答、组合指南已实质覆盖、已独立成页。后台标记或地名出现不能等同覆盖。
4. 每个城市保留可追踪记录。每篇页面必须回答当地独特问题；不批量生成仅替换地名的入口页。
5. 高端小众额外检查住宿与睡眠、道路与行李、真实解释和主持、可约性与备用安排。不能用luxury/private/exclusive堆词代替交付证据。
6. 页面递进为地名识别→是否值得去→停留与基地→取舍与实用安排→示例行程→真实匹配产品/定制。没有真实产品则products为空。
7. 关键词先按地名、别名、比较、住宿、交通、体验、路线构建。再按国家与查询检查实际结果、搜索意图和竞争；不能保证任何词都能搜到本站。
