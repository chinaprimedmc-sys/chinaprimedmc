# Beijing search intent and editorial ownership

Local editorial plan, 10 November 2026. This is an intent map, not measured keyword
research. No live SERP review, Search Console export, search volume or keyword
difficulty data was available. Priorities reflect relevance to AVIORA's services and
the specificity of a travel decision; competition remains unverified.

## Priorities and implementation

1. Lead with the destination's commercial planning intent. Use supporting long-tail
   questions where a useful answer naturally belongs, rather than repeating exact
   phrases across headings and paragraphs.
2. Keep traveler-specific planning sections concrete: a child's rest schedule,
   walking duration, stairs, hotel lifts and distance from vehicle to entrance.
3. Use descriptive links that explain the next decision. A product recommendation
   must give a reason to choose it; an informational question should link to its guide.
4. Preserve the distinction between visible facts, recommendations and services
   confirmed only in the written proposal. Machine-readable FAQ answers must continue
   to derive from the same visible FAQ content.

## Measurement after publication

Use Search Console query/page pairs to assess impressions, clicks and competing
landing pages for each intent. Review whether broad destination planning queries
land on the destination and transactional itinerary queries reach products. Multiple
pages appearing for a query alone does not prove harmful cannibalization: check
intent and performance before consolidating content. Use the existing destination
CTA placements to measure product clicks; qualified enquiries require separate
conversion evidence. Adjust priorities after real data is available.
