## 结果边界

- 日期区间早于本轮改动发布；本轮未部署。这是历史基线，不能把上述流量归因于本轮优化。
- 平均排名是聚合值，不是某个国家／设备上的固定排名；全站 CTR 不能套用到每篇文章。
- 发布后先核验抓取、索引与 Google 选定 canonical，再比较等长区间并按查询、页面、国家和设备分组。季节、品牌活动与其他页面变化均可能影响结果，前后变化不自动证明因果。
- 询盘需结合线上 CTA、成功提交事件及 CRM 有效记录另行核验，不把点击等同于有效询盘。
- 界面显示 generative AI features report 入口，但本次未读取数据，不能声称获得 AI Overview 引用。

下一步外部核验优先读取查询对应页面、九个核心 URL 索引结果，以及正式页是否包含当前品牌问答。品牌故事已清楚时，重复改写无法替代这些证据。
