## Google AI Overview

官方方法参考：https://developers.google.com/search/docs/appearance/ai-features 。本轮未成功在线读取，不标为本日核验。

Google AI 功能沿用一般搜索基础；没有专用的 AI Overview schema 或保证收录的申请入口。页面需可抓取、可索引并具备摘要展示资格。当前本地 robots 允许 Googlebot，默认产品 metadata 为 index/follow，max-snippet 为 -1。仍须在部署后确认实际响应、canonical、CDN/WAF、渲染正文和 Search Console 状态。

上线验收：

1. 用 Search Console URL 检查分别验证六条 canonical 的线上状态及抓取内容；必要时申请索引。
2. 检查真实 HTML 包含摘要、事实、FAQ 和可点击来源；执行 Rich Results Test／Schema Validator。FAQPage 正确不代表旅行站能获得 FAQ 富结果。
3. 记录目标国家、语言、日期与查询，人工查看 AI Overview 是否出现及是否链接本站。结果会变化，不以一次搜索证明普遍覆盖。
4. Search Console 的 AI 搜索流量通常并入网页搜索表现，不能假定可单独筛出所有 AI Overview 引用。结合落地页、查询、询价和人工抽查记录判断。

## 官方外链和反向链接

本站指向官方机构属于引用外链；其他网站链接本站才是反向链接。增加官方出站链接可以帮助读者溯源，不等于官方推荐本站，也不直接创造反向链接。此次没有新增任何第三方反向链接。

优先执行以下可核实的获链路径，不向 UNESCO、政府或博物馆索要无关商业推荐：

| 优先级 | 路径                               | 上线前可准备的材料                                      | 合格链接与衡量                                                                             |
| ------ | ---------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| P1     | 真实签约海外旅行顾问／旅行社合作页 | 明确产品范围、联系人、接待主体和服务事实的英文 DMC 介绍 | 真实合作方在有上下文的 China supplier 页面自行选择链接；记录来源 URL、目标页和实际推荐询价 |
| P1     | 有真实经历的海外客户／旅行作者     | 提供其实际行程资料和图片使用授权，保留独立评价权        | 作者自主报道并引用实际产品或规划指南；不购买好评，不换锚文本                               |
| P2     | 有资格加入的旅行行业协会／商会目录 | 核实法人、资质、会籍条件和公开资料                      | 入会后真实成员目录；未入会不宣称会员，不用无关批量目录                                     |
| P2     | 英语媒体的具体选题与专家采访       | 可核查的十天与十二天行程比较、景区步行与交通选择说明    | 编辑自然引用有用的原创材料；不把官方信息改写包装成独家数据                                 |
| P2     | 真实会展／商务接待伙伴资源页       | 经授权的服务案例和双方确认的服务边界                    | 只有实际合作且对读者有帮助时刊登                                                           |

建议首批链接资产：完善已有十天与十二天比较文章，明确九晚／十一晚、城市夜数、交通日与恢复时间；完善慕田峪步行及索道决策指南。它们比纯报价页更适合被规划类文章引用。尚未测量海外搜索量或获链率，不虚构预计权重、流量或排名。

运营表至少记录：候选机构、真实关系／资格、来源页、目标页、读者价值、联系方式来源、联系状态、刊登 URL、赞助关系和推荐询价。此轮只制定方案，未发邮件、提交目录或联系任何第三方。付费展示必须披露且使用 rel="sponsored"（或 nofollow）；不购买传递排名信号的链接、不做互链网络或批量垃圾外链。

Google 链接垃圾政策参考：https://developers.google.com/search/docs/essentials/spam-policies#link-spam 。同样未在本轮在线核验。
