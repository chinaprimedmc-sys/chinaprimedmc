# AVIORA 产品分类与存在理由

定稿日期：2026-11-10。共 19 个现有产品。代码分类来源为 `content/tours/classification.ts`。

## 三个大类

1. **一日体验（5 个）**：客人已经选好城市，只把一天交给你。
2. **多日主题线路（11 个）**：客人按想看什么、同行人和喜欢的节奏，选择一条已有路线。
3. **专门需求定制（3 个）**：饮食礼拜、静修或商务任务先于观光路线，已有行程展示设计范例。

每条产品只有一个主子类。家庭、情侣、摄影、饮食等是可重叠的辅助标签，不决定主分类。所有产品都可以按日期和同行人调整；“专门需求定制”的特点是特殊需求本身决定行程设计。

## 网站已同步

- 三个大类由主子类自动派生，库存保持 5／11／3。
- Journeys 目录新增 Journey focus 子类筛选，桌面与手机共用，筛选可写入和恢复 URL。
- 产品卡片与详情页类别名称使用同一分类数据。
- 每条产品记录了存在理由、优先客群和与近邻产品的边界。
- 多代同行标签优先用于亲子与成熟旅客慢游产品；10 天初访按其主要购买理由分类。

新增产品时，先说明它解决了什么现有产品没有解决的问题，再分配唯一主子类、客群及与近邻产品的边界。仅仅共享城市、适合儿童、可以摄影或换一家酒店，不足以形成新产品。若只是配置不同，应先作为现有产品的版本。

分类只回答“产品为什么存在、属于哪里”，不代表价格、供应与行程承诺已核实，也不代表优化方案中的线路改动已经执行。
