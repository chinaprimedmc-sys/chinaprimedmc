# China Prime DMC V2.0

World-class frontend foundation for a premium inbound China travel platform.

Current phase: project foundation only.

No homepage, destination page, trip page, or business functionality is developed in this phase.

## Commands

- `pnpm dev`
- `pnpm build`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm format`

## Stack

- Next.js 16 App Router
- TypeScript strict mode
- Tailwind CSS v4
- shadcn/ui architecture
- Radix UI primitives
- Framer Motion and GSAP-ready motion system
- Lenis smooth scroll
- next-themes
- TanStack Query
- Zustand
- React Hook Form and Zod
- Next Metadata API, JSON-LD, sitemap, robots
